# Phase 0 착수 계획

## 기준일
- 2026-02-20

## 1차 범위 (MVP)
- IT 개발 도메인 500개 용어 수집
- 디자인 도메인 220개 용어 수집
- 용어별 4단계 설명, 관계(상위/유사/하위) 매핑
- 도메인 진단 퀴즈 15문항 설계

## 생성 규칙
- difficulty 분포: novice 15%, beginner 35%, intermediate 35%, advanced 15%
- 용어마다 source_urls 최소 2개
- 마지막 검수자/검수일 필수

## 작업 순서
1. 카테고리 3단계 트리 확정
2. 용어 원본 수집
3. 4단계 설명/예시/퀴즈 생성
4. 그래프 관계 검증
5. 샘플 학습 세션으로 품질 점검
