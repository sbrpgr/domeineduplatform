01

핵심 UX 콘셉트

플랫폼이 전달해야 하는 경험의 방향성

Design Principle

이 플랫폼은 "교과서"가 아닌 "단어장 앱"의 감각으로 설계한다. 사용자는 읽는 것이 아니라 반복적으로 만지고, 맞히고, 레벨업하는 경험을 한다. 모든 화면은 "오늘 10개 학습"이라는 단일한 루프로 수렴해야 한다.

Swipeable

카드 기반 학습

모든 용어는 단어장 카드 형태. 스와이프로 다음 용어, 탭으로 펼치기. 복잡한 네비게이션 없이 학습이 진행된다.

Contextual

맥락 중심 설명

정의 → 예시 → AI 명령어 예시의 3단 구조. 단순 암기가 아닌 "언제, 어떻게 쓰는가"를 중심으로 학습.

Progressive

점진적 난이도

같은 용어도 레벨에 따라 다른 설명. 입문자는 비유, 전문가는 엣지케이스. 사용자가 성장할수록 콘텐츠가 깊어진다.

Connected

연결된 지식망

모든 용어는 관련 개념과 노드로 연결. 하나를 클릭하면 생태계가 펼쳐진다. 지식이 점처럼 쌓이는 게 아닌 망처럼 확장된다.

UX Rule

이미지는 "있으면 더 좋음"이 아닌 "기본 포함"이 원칙. 이미지가 없는 용어에는 도메인별 컬러 아이콘을 자동 배정한다. 빈 카드는 허용하지 않는다.

인터랙션 명세
📱 스와이프 좌/우 → 이전/다음 용어
👆 탭 (해설 영역) → 접힌 예시 펼치기
🔄 레벨 탭 전환 → 해설 페이드 교체 (300ms)
📌 우상단 북마크 → 즉시 저장 + 애니메이션
🕸 연관 용어 버튼 → 하단 드로어로 그래프 슬라이드업

사용자의 학습 동기를 지속적으로 유지시키는 보상 구조 전체 설계

설계 원칙

게이미피케이션은 장식이 아닌 습관 형성 엔진이다. 매일 학습하게 만들고, 성장감을 느끼게 하고, 커뮤니티와 연결되게 한다. Duolingo의 스트릭 + Anki의 간격반복 + RPG의 레벨업이 합쳐진 구조.
