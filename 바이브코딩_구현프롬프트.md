## ▌PHASE 3: ADAPTIVE LEARNING ENGINE

Implement the complete backend learning system.

### 3-1. SM-2 Spaced Repetition (Modified)

```python
def calculate_next_review(term_id: str, user_id: str, quality: int) -> datetime:
    """
    quality: 0-5 scale
      0 = complete blackout
      1 = incorrect, remembered on seeing answer
      2 = incorrect, easy recall
      3 = correct with difficulty
      4 = correct with hesitation
      5 = perfect recall

    Returns: next review datetime
    """
    record = get_user_term_record(user_id, term_id)

    if quality < 3:
        record.repetitions = 0
        record.interval = 1
    else:
        if record.repetitions == 0:
            record.interval = 1
        elif record.repetitions == 1:
            record.interval = 6
        else:
            record.interval = round(record.interval * record.easiness_factor)
        record.repetitions += 1

    record.easiness_factor = max(
        1.3,
        record.easiness_factor + 0.1 - (5 - quality) * (0.08 + (5 - quality) * 0.02)
    )

    record.next_review = datetime.now() + timedelta(days=record.interval)
    save_user_term_record(record)
    return record.next_review
```

### 3-2. IRT-Based Adaptive Quiz

```
- Each quiz question has a difficulty parameter (β) from -3 to +3
- Each user has an ability estimate (θ) initialized from onboarding score
- After each answer, update θ using Maximum Likelihood Estimation
- Select next question where P(correct) ≈ 0.70 (optimal challenge point)
- Stop quiz after:
  - 20 questions answered, OR
  - θ estimate standard error < 0.3 (sufficient precision)
- Output: final θ → map to level (입문/기초/중급/고급)
```

  visibility VARCHAR(20) DEFAULT 'private', -- private | team | public
  slug VARCHAR(100) UNIQUE, -- for public URL
  color_theme VARCHAR(7), -- hex color for branding
  logo_url TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE custom_terms (
  id UUID PRIMARY KEY,
  dictionary_id UUID REFERENCES custom_dictionaries(id),
  term_ko VARCHAR(200) NOT NULL,
  term_en VARCHAR(200),
  one_line_definition TEXT,
  definitions JSONB, -- {novice, beginner, intermediate, advanced}
  usage_examples JSONB,
  ai_prompt_example TEXT,
  related_platform_term_ids UUID[], -- links to platform terms
  related_custom_term_ids UUID[], -- links within same dictionary
  difficulty VARCHAR(20),
  tags TEXT[],
  ai_generated BOOLEAN DEFAULT FALSE,
  ai_confidence JSONB,
  order_index INTEGER,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE dictionary_members (
  dictionary_id UUID REFERENCES custom_dictionaries(id),
  user_id UUID REFERENCES users(id),
  role VARCHAR(20), -- owner | editor | viewer
  invited_at TIMESTAMPTZ DEFAULT NOW(),
  PRIMARY KEY (dictionary_id, user_id)
);
